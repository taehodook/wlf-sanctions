# manual/ — KoFIU 수동 반입 (평상시 비워둠)

KoFIU 명단은 국가법령정보센터에서 **자동 수집**됩니다. 이 폴더는 자동 수집이
실패했을 때만 씁니다(사이트 개편·서식 변경·사내망 차단 등).

넣는 방법: 금융위 고시 별표 파일(xlsx / csv / pdf)을 이 폴더에 커밋합니다.
파일명에 `kofiu` / `제한대상` / `금융거래등제한` 중 하나가 들어가야 인정합니다.

    manual/kofiu_금융거래등제한대상자_20260729.xlsx

이 폴더에 파일을 올리면 워크플로가 자동으로 재수집합니다.
